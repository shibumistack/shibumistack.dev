# my-shibumi-blog

Built with [Shibumi Stack](https://shibumistack.dev): Bun, Hono, Marked.

## Getting started

```sh
bun install
bun dev
```

Write posts in `content/` as markdown files with frontmatter. The blog discovers them automatically.

## Stack

- **Bun**: runtime, package manager, test runner
- **Hono**: route layer
- **Marked**: markdown to HTML
- **gray-matter**: frontmatter parsing
