Extensions

Add features to your project. Copy source, own the code. Install with bun run shibumi add <name>.

auth

Cookie sessions with password or magic-link login. Zero npm dependencies — uses Bun.password and bun:sqlite.

official shibumi
extension
$ bun run shibumi add auth

images

Automatic WebP optimization. Serves WebP on the fly via middleware, keeps originals untouched. No HTML changes needed.

official shibumi
extension
$ bun run shibumi add images

email

Transactional email via Resend. One function call: sendEmail({ to, subject, html }).

official shibumi
extension
$ bun run shibumi add email

Write your own

An extension is a directory with a manifest, agent guidance, and source files:

src/extensions/my-ext/
├── manifest.json
├── agents.md
└── files/
    └── src/
        └── ...

Publish to npm. Install with bun run shibumi add my-ext.
