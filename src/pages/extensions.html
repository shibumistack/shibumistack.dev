auth

Cookie sessions with password and login-link sign-in. Bun.password hashing, sha256-hashed tokens, CSRF-protected mutations, rate limiting, a bot honeypot, and SQLite tables installed through the project's migration stream. Needs the full-stack database.

bun:sqlite Bun.password migrations

email

Resend send helper over plain fetch (no SDK dependency), environment validation, escaped template rendering, webhook signature verification, and fixture tests. No tables.

plain fetch RESEND_API_KEY webhooks

Package layout

A package contains a manifest, a named agents.md guide, and files with fixed target paths. Installation must preview every write and stop on conflicts.

manifest.json
migration.sql
agents/
  feature.md
files/
  src/
    ...

Bundled extensions ship inside the versioned create-shibumi package, embedded in the vendored scripts/shibumi.ts and covered by its checksum. Installation touches no network. Removal deletes code and reverses edits; tables are never dropped by tooling.
