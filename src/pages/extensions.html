Extensions

Add features to your project. Copy source, own the code.

Install an extension

› bun run shibumi add name

Auth

cookie sessions

Password or magic-link login. Zero npm dependencies — uses Bun.password and bun:sqlite.

bun run shibumi add auth
  • Session management with 7-day expiry
  • Password hashing with Bun built-in
  • Magic link tokens (15-minute, single use)
  • Auth middleware for protected routes
  • Auto-wires into your app via hooks

Images

webp optimization

Serves WebP on the fly. Originals stay untouched. No HTML changes needed.

bun run shibumi add images
  • Intercepts image requests via middleware
  • Converts to WebP with Bun.Image
  • Caches results in public/images/optimized/
  • Originals never modified or deleted
  • Auto-wires into your app via hooks

Email

transactional

Send emails via Resend. One function call.

bun run shibumi add email
  • sendEmail({ to, subject, html })
  • Requires RESEND_API_KEY in .env
