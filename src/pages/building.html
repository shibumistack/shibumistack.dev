Product contract.

available

Shibumi Forms. Hosted pre-alpha and self-hosted Bun, Hono, and SQLite source.

cli

create-shibumi. Generate a SQLite full-stack app, a blog, or a static site.

deploy

VPS first. Generate current Ship source, loopback-only Compose, health checks, and resource limits.

tests

Packed fixtures. Each generated project must install, test, build, run, and deploy without paths back into the CLI repository.

data

SQLite under /data. Full-stack projects include Drizzle migrations, backup, restore, and persistence tests.

state

Alpine first. Add Nanostores only when separate browser components share state.

security

Checks in generated code. Validate input, protect mutations, and bind app ports to loopback.

extensions

Extensions copy source. Auth, email, and uploads bring their routes, config, migrations, tests, and agent guide.

agents

Named instructions. Each extension keeps agents/<name>.md beside the source it adds.

server

shibumi-server. A VPS deploy service that checks signed requests, host capacity, Compose config, image identity, and health before replacement. Images build locally. One previous image remains available for up to 12 hours.
