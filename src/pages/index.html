What it is

Three tools. create-shibumi writes a Bun app with tests and deploy config. shibumi-server turns a €5 VPS or your homelab into a host for all your apps. Shibumi Forms gives static sites a working form.

Principles

Simplicity, patience, humility. Every job gets one curated library. Features arrive as source, and instructions for your coding agents arrive with them. If a file lands in your repo, you can read it.

Your coding agent gets a manual

Every generated project includes a root agents.md: route locations, data rules, available checks, and files that need extra care.

Install the auth extension and agents/auth.md arrives with it, so your coding agent learns the rules at the same moment the code does.

Extensions write source into your repo

Add auth, email, or uploads as plain .ts files: routes, config, migrations, tests, and agent instructions you can edit.

Deploy to your VPS or homelab

Static, web, and full-stack projects use the same VPS deployment path.

shibumi-server verifies signed requests, host capacity, image identity, and health. Install pinned v{{server-version}} on the Linux host with curl -fsSL https://shibumistack.dev/install/server | bash.

With the server installed, run bun ship, included in every generated project. It builds committed code locally and deploys it:
