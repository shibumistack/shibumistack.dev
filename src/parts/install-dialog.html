渋み Create a Shibumi project

Start locally. You need Bun 1.4.4 or newer; install Bun or run bun upgrade. No Docker, domain or VPS is needed yet.

In the directory that will contain your project:

› bun create shibumi@latest my-app

For a first app, choose Bun full-stack app, then Later for deployment. When creation finishes:

› cd my-app && bun dev

Open localhost:9001. Click Count, then reload; the value should remain.

Follow the quick start for blog, static and deployment instructions.
